# Universal Media Server - Your Media on Your Network

Universal Media Server is a home server for videos, music, and photos you may share. Players on the same network can browse what you pointed at. The files stay on the disk you chose.

---

## Product Snapshot

You add a folder, the server lists what it can read, and a TV or a player app asks for an item. Codecs matter only as far as playback. They do not unlock a disc. Logs tell you what was requested from this server, which is useful when a file fails, and they are private because titles can be personal.

Start with one folder of your own exports or rips you were allowed to make. Watch one file on one player in the house. Then add more. A library of every drive will include other people's files if this PC is shared.

## Highlights

- Folders you select, not a built-in catalog
- Playback to devices on your network
- Users you choose, if you turn access control on
- Logs of requests to this server
- One test file before a large library
- No role as a downloader of films you do not own

---

## Live Production

A living-room player can open a recording you made or a file a publisher gave you. That is the job. Do not add indexes of titles you have no file for. If a roommate should not see a folder, do not share the parent directory. Share the specific folder.

Transcoding uses CPU. If the picture stutters, try a file that the player can read directly before you raise quality. The original on disk is still the master. The server can be stopped when you do not want the library visible.

---

## Who Is Allowed In

Turn on a password or a user list before the server is reachable past your router. A test from a phone on your Wi-Fi is enough. A port opened to the world is a later decision, and only if you understand who can connect. Remove a shared folder when the event is over. The files do not need the server running to remain on disk.

---

## What Stays Out

Do not point the library at a download folder full of files you are not allowed to keep. Do not use the server to publish someone else's private videos because the path was visible. A codec pack from an advertisement is not required to serve a file your player already opens.

---

## Setup Path

Prerequisites: Media you may share, and a network that is yours.

1. Install Universal Media Server and add one folder.
2. Play one file from a player on the same network.
3. Set a password or a user if anyone else can join that network.
4. Read the log only to see why a file failed.
5. Stop the server when you do not want the folders listed.

---

## Who Benefits

Universal Media Server fits a house that wants your files on a TV without copying them by hand. It does not fit a public share, a catalog you do not own, or a PC where other users' private folders would be swept in.

---

## Fixes

The player sees nothing: you are not on the same network, or the folder is empty of files it can list. A title stutters: try a direct play of a simpler file. The wrong videos appear: remove that folder from the share. Do not open a port to chase a missing title.
